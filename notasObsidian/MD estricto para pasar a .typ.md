## Usar `=` en lugar de `#`

Siempre dejar dos saltos entre párrafos

`**` para **negritas** (aunque .typ use `*`)
`*` para *cursivas*  (aunque .typ use `_`)

No usar `[[enlace]]` para los enlaces, .typ no los reconoce; en cambio usar [Derivación](Derivacion)
